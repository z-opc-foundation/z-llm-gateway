z-llm 控制台

管理面 REST 端点:

  • GET /z-llm/admin/overview — 概览
  • GET /z-llm/admin/vendors — 各 vendor 凭据数 / 模型数
  • GET /z-llm/admin/vendors/{vendor}/models — 列模型
  • GET /z-llm/admin/credentials — 凭据清单
  • GET /z-llm/admin/api-keys — API Key 清单
  • GET /z-llm/admin/rate-limit — 限流桶快照
  • GET /z-llm/admin/health — 健康检查

对外协议端点:

  • POST /v1/chat/completions — OpenAI Chat Completions 兼容
  • POST /v1/messages — Anthropic Messages API 兼容
